Algorithms and Programming in Python

ENSAI, second year · Rennes

Course description

The course covers numerical programming in Python and its use to implement optimization and estimation methods for machine learning: least squares, regularized regression with gradient and proximal methods, and Gaussian mixture models. Each session combines a lecture with implementation exercises in Jupyter notebooks.

Prerequisites: basic programming in any language, elementary linear algebra, means and variances, and running commands in a terminal.

Assessment

A three-hour written exam in class, consisting of one exercise closely related to the sessions: adapting an optimization algorithm from the course or applying the course methods to a real-world problem. Online documentation is allowed; LLM assistance is not.
